# nvidia-lib

Reusable NVIDIA NIM helper configured from the `models.json` generated by `nvidia-cli`.

```python
from lib.nvidia import NVIDIA

nvidia = NVIDIA()
result = nvidia.query("why is the sky blue", model="minimax")
print(result)
```

`model="minimax"` is resolved by unique partial match, e.g. to `minimaxai/minimax-m3`.

Streaming:

```python
for chunk in nvidia.stream("Explain HTTP streaming", model="minimax"):
    print(chunk, end="", flush=True)
```

For chunk timing/debug metadata use `nvidia.stream_events(...)`.


## Async API

```python
import asyncio
from lib.nvidia import NVIDIA

nvidia = NVIDIA()

async def main():
    result = await nvidia.async_query("hello", model="minimax")
    async for event in nvidia.async_stream_events("hello", model="minimax"):
        print(event["content"], end="")

asyncio.run(main())
```
